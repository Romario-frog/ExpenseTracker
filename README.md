## What this app is about
This is a simple and convenient application for tracking your finances.
It lets you quickly log income and expenses and instantly see your balance.

Nothing extra — just what you actually need every day.

---

## Key features

- Add income and expenses
- Choose categories (food, education, etc.)
- Add a comment to each transaction
- Automatic balance calculation
- Full transaction history
- Delete individual entries
- Clear the entire history
- Automatic data saving (nothing gets lost)
